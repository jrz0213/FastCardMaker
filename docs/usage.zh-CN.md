# FastCard Maker 操作指南

本插件基于 [FastWordQuery（FastWQ）](https://github.com/sth2018/FastWordQuery) 开发，保留原项目的作者署名与许可证。

按下面的步骤配置 AI 或词典，再处理笔记。截图中的字段、词典和模型为示例，请使用自己的配置。

首次使用建议按“设置 AI → 配置字段 → 少量试查”的顺序操作。AI 制卡与词典查询可以单独使用，也可以在同一份配置中为不同字段选择不同来源。

## AI 制卡

### 1. 准备笔记并设置 AI

先在 Anki 添加笔记，填写主题、问题或学习材料。例如建立“主题”“问题”“回答”三个字段，前两个填写内容，最后一个留给 AI。插件将结果填入已有笔记，卡片正反面的显示由 Anki 模板决定。

打开 **FastCM → 选项 → AI 设置**：

1. 新增一个连接配置，填写名称。
2. 在 **API 地址（含接口路径）**中填写包含接口路径的完整地址，再填写 API Key 和模型名称。
3. 填写 API Key 和支持该接口的模型，点击 **确定** 保存。
4. 如需所有回复遵守同一要求，在 **Skill** 中填写，例如“使用中文，回答简洁，给出具体例子”。

![AI 连接设置](images/user-guide/zh-CN-ai-settings.png)

完整地址示例：`https://api.deepseek.com/responses`，或 `https://maas.qianwenaiapi.com/compatible-mode/v1/responses`。选择服务预设后会填入默认的完整接口地址，无需再选择“接口模式”：OpenAI、DeepSeek、Qwen 默认 Responses，Gemini 默认官方 Interactions，Claude 默认官方 Messages。模型名称仍可自由填写，但需支持对应接口。已有配置保持原地址；需要切换接口时修改完整地址，并检查自由参数。

Qwen/百炼的地域与业务空间可能需要专属地址，不能把所有账户锁定到一个域名。请以自己控制台的完整地址为准。Gemini 参数写在 `generation_config` 中（如 `temperature: 1`、`thinking_level: "minimal"`）；minimal 并非完全关闭思考。Claude 的 `max_tokens` 默认 4096，可在更多配置中调整。

打开 **更多配置 → 自由参数（JSON）**，可修改预填值或添加接口支持的参数。例如 Responses：

```json
{
  "temperature": 1,
  "reasoning": {"effort": "none"},
  "top_p": 1
}
```

预填温度 1、关闭思考只是可编辑示例，不会按模型自动筛选。DeepSeek Chat 使用 `"thinking":{"type":"disabled"}`；Qwen（包括 Responses）使用 `"enable_thinking":false`。按输入框下方备注调整，不支持的参数自行删除，JSON 中不要写注释。`content` 能否作为顶层参数取决于接口；要说“继续上文”，直接在对话输入框发送即可。

每分钟发送数、请求超时、连接超时和重试次数在 **插件设置 → AI 设置** 中统一调整。

### 2. 配置目标字段和提示词

在选项页选择笔记类型，然后逐行设置：

1. 用左侧单选按钮选择来源字段，例如“主题”。
2. 不需要更新的字段保持 **忽略**。
3. 将“回答”字段的内容来源选为刚才的 AI，取消 **忽略**，填写提示词。
4. 点击 **确定** 保存字段配置。

重新打开选项页会回到上次保存的笔记类型和配置标签，不改变浏览器查询使用的默认配置；未保存退出的修改不保留。

![来源字段、AI 和提示词](images/user-guide/zh-CN-configuration.png)

一条提示词可以引用多个字段：

```text
结合{{主题}}，回答这个问题：{{问题}}
要求：先直接回答，再给出一个例子，不超过200字。
```

发送时会替换成当前笔记的实际内容。字段名必须完全一致；被引用的字段不能配置为 AI 输出字段。提示词写在目标字段行中，字段引用不要放到 Skill 中。

需要表格时，可以直接写“用 Markdown 表格比较……”。同一笔记可以为不同目标字段分别填写不同要求。

### 一个完整例子：学习概念

1. 在 Anki 建立“主题、问题、回答、对比”四个字段，添加一条笔记：“主题”填写“统计学”，“问题”填写“相关与因果有什么区别？”。
2. 在选项中选中这个笔记类型，将“主题”设为来源字段。“主题”和“问题”保留原内容，不设为 AI 输出。
3. 取消“回答”的忽略，选择 AI，在提示词填写上面的多字段示例。
4. 取消“对比”的忽略，选择同一个 AI，提示词填写：`围绕{{主题}}中的{{问题}}，用 Markdown 表格列出定义、例子和常见误区。`
5. 保存后，在浏览器只选中这一条笔记进行查询。结果会分别写入“回答”和“对比”；若背面看不到内容，在 Anki 的“卡片…”中把这两个字段加入背面模板。

学习单词时也一样：来源字段填单词，其他字段分别要求释义、例句或近义词。无需自己编写拆分 JSON 的脚本，合并发送会按目标字段自动分配结果。

### 3. 先试查，再批量处理

先在 Anki 浏览器选中几条笔记，点击 **FastCM → 查询选中项**，检查生成内容。

满意后，打开 **FastCM → 全类型查询**：

1. 勾选需要处理的笔记类型。
2. 为每个类型选择已保存的配置。
3. 点击 **查询**，处理所选类型的全部笔记。

![选择笔记类型和配置后查询](images/user-guide/zh-CN-type-query.png)

从浏览器打开时，所选笔记涉及的类型会默认勾选；从首页打开时自行勾选。修改字段配置后先保存，再查询。已有内容默认是否跳过取决于该行的 **跳过有值项**；需要重新生成时取消这一项。

### 4. 发送方式、表格样式和后台运行

打开 **插件设置 → AI 设置**，选择：

- **按卡片合并发送**：默认方式，同一笔记中使用同一个 AI 连接的目标字段合并请求。
- **逐字段发送**：每个目标字段单独请求。
- **Markdown**：将回复中的表格、列表等转换成卡片格式，默认开启。
- **CSS 注入**：需要表格样式时开启，在始终显示的列表中勾选生效类型。只有 CSS 编辑区折叠，点击 **查看／编辑全局 CSS** 展开。默认关闭；对应类型的笔记内容实际更新后才应用样式。

**词典设置**中调整词典线程及匹配选项，**通用设置**中调整语言、填空格式和定时制作。

![发送方式与格式设置](images/user-guide/zh-CN-settings.png)

查询时点击 **后台运行**，可继续使用 Anki。通过 **FastCM → 任务进度** 查看状态；结束后查看结果，点击 **完成任务** 收起。请保持 Anki 打开，结果每隔 30 秒保存一次，任务结束时保存剩余内容。

中途退出后，如启动时出现恢复窗口，点击 **恢复结果** 写入已经缓存的内容；点击 **稍后** 可留待处理。

### 5. 可选：定时制作新笔记

在选项页点亮要自动使用的配置星星并保存。每个笔记类型选择一份配置。

打开 **插件设置 → 通用设置**，勾选启用定时制作，设置间隔（如 5 分钟）、选择笔记类型并保存。它只处理启用后新增笔记的空字段；上一批未结束时跳过本轮。

发现待处理笔记后，顶部显示 **10 秒倒计时**，可选 **立即运行** 或 **跳过本次**；关闭提示也会跳过，不操作则自动开始。自动任务完成后不额外弹通知，从任务进度查看结果。Anki 必须保持打开。

![自动运行前的倒计时](images/user-guide/zh-CN-automatic-countdown.png)

## 词典与解析脚本

### 1. 添加词典并配置字段

1. 打开 **词典管理 → 词典目录**，添加本地词典文件夹。MDX 的配套 MDD 和资源文件应保持完整。
2. 回到 **本地词典** 或 **网络词典**，勾选需要启用的词典并保存。
3. 在选项页选择包含单词的来源字段；为目标字段选择词典和数据项，取消 **忽略** 后保存。
4. 在浏览器选择少量笔记试查，确认后再使用全类型查询。

![勾选启用的词典](images/user-guide/zh-CN-dictionary-manager.png)

词典文件移动后，恢复路径并重新检测即可。显示不可用时不会自动改选其他词典。需要整条词条时选择默认解析；需要独立的释义、例句、发音等数据项时选择对应脚本。

### 2. 用 AI 生成或修改解析脚本

在词典旁点击 **AI 解析**：

1. 选择已配置的 AI。这里使用你填写的命令，不使用连接的 Skill。
2. 保留默认的三个样本词，或填写词典收录的三个不同词。
3. 在 **命令** 中写清希望提取的内容，例如“分别提取释义、音标和发音，检查 JS 是否修改音频路径”。
4. 按需勾选 **发送 HTML、发送 JS、发送原脚本**。修复发音时建议同时发送 HTML 和 JS；修改已有脚本时发送原脚本。
5. 点击 **发送三个词条并生成**，检查提取预览和生成脚本，点击 **保存脚本**。
6. 返回词典管理勾选启用，再到选项页选择对应数据项并保存。

![样本、命令与附件选择](images/user-guide/zh-CN-script-generator.png)

### 3. 调试、继续对话和导入记录

生成前可开启 **自动调试**，生成后也可点击 **调试一次**。在 **信息历史** 查看结果；调试失败时展开消息，检查词条、字段和错误详情。调试不改卡片，只检查本次生成的导出方法和三个样本，保存后仍建议少量试查。

![连续对话、角色颜色与底部输入框](images/user-guide/zh-CN-script-information.png)

- 在底部输入框填写后续要求，点击 **发送消息**。例如“根据调试错误修复发音路径，保留其他字段”。
- 希望 AI 结合上下文时，勾选 **携带当前会话全部对话**；根据错误修复时勾选 **携带最近调试结果**。
- 每条消息最多预览五行，点击 **展开／收起** 查看全文。需要分享时使用 **复制全部** 或 **导出 Markdown**。
- 每次打开窗口开始新会话。点击 **导入之前的会话**，可选择该词典的记录继续使用。
- AI 修改后再次检查预览并 **保存脚本**。需要撤回脚本修改时，使用 **恢复旧脚本**；回收站中的备份保留七天。

携带历史和源码会增加 Token 消耗，过长可能超过模型限制。遇到超限时取消携带历史或开始新会话。


## 常见操作问题

- **点击查询后没有内容**：检查目标字段是否取消“忽略”、是否选择正确来源，以及“跳过有值项”是否跳过了已有内容；在“任务进度”查看失败详情。
- **想重做一个字段**：取消该字段的“跳过有值项”，其他字段勾选“忽略”，保存配置后只选少量笔记重查。重新生成会替换目标字段原内容。
- **修改后运行还是旧效果**：AI 连接窗口和选项主窗口分别点击“确定”；全类型查询再选这份已保存配置。
- **连接或参数报错**：核对 API Key、模型和完整接口地址；若提示不支持某参数，在“更多配置”的 JSON 中删除该参数再试。
- **词典或发音缺失**：确认本地 MDX、配套 MDD 与资源路径可用，重新检测；针对 JS 改写音频路径的词典，生成脚本时同时发送 HTML 和 JS，并通过调试和少量试查验证。
- **找不到后台窗口**：从“FastCM → 任务进度”重新打开。最小化不停止任务，关闭 Anki 则无法继续请求；已经缓存的结果可在下次启动时恢复。
